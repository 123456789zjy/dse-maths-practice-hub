# DSE Maths Practice Hub

[Open the practice workbook](https://123456789zjy.github.io/dse-maths-practice-hub/)

The public workbook contains 2,564 questions: 1,084 questions from 34 HKDSE papers, 1,472 ICY Maths Beyond practice variants, and 8 original questions. Answers and marking references are included. Handwriting and progress are stored in the student’s browser.

[See the latest GitHub release](https://github.com/123456789zjy/dse-maths-practice-hub/releases/latest) for the Pages deployment ZIP. The [November 27 maintenance update](https://github.com/123456789zjy/dse-maths-practice-hub/releases/tag/bank-2026-11-27) also includes a separate ZIP with the development workflow, roadmap, and question-bank validation changes.

The GitHub Pages workflow verifies the deployment ZIP and publishes the `docs/` folder inside it. The `docs/` folder in the repository contains the original pilot build.
